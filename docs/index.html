An implied-volatility surface that shows where the quotes end.

Give it an option chain. It solves each quote for implied volatility, fits a surface in total variance, and writes one HTML file you can open anywhere. No server, no API key.

python -m pip install -r requirements.txt
python main.py

With no input it builds a synthetic chain, so the first run works offline in seconds.

This is the default run

The surface above comes straight from the tool's own code on its default synthetic chain: spot 100, rate 4%, dividend yield 1.5%, eight maturities from one month to two years, 5 basis points of price noise.

Most dashboards draw a smooth sheet edge to edge and leave you to guess which parts a trade ever touched. This one keeps the difference visible: in the term-structure and smile panels of the dashboard, a line simply stops where the quotes stop.

How a chain becomes a surface

  1. Read the chain

    Synthetic by default, or your own CSV of strike, type, price and maturity. Bad rows are set aside and counted, not fatal.

  2. Put every strike on one scale

    Forward F = S e(r−q)T, then log-moneyness k = ln(K/F).

  3. Keep the liquid side

    Only out-of-the-money quotes: puts below the forward, calls at or above it.

  4. Solve for implied volatility

    Newton where vega is healthy, Brent where it is not. A quote is accepted only when the volatility itself has converged, not just the price.

  5. Fit in total variance

    Interpolate w = σ²T over (T, k) with a thin-plate RBF, or a spline if you ask for one, and mark which grid nodes the quotes actually cover.

  6. Write the dashboard

    A 3D surface plus smile and term-structure panels in a single Plotly HTML file, with calendar and butterfly checks printed alongside.

Run it on your own data

Your CSV

Columns strike, type, price, and either T in years or expiry with a valuation date. Rates and yields are decimals.

python main.py --csv chain.csv --spot 100 --rate 0.04 --div 0.01

A live listed chain

Needs yfinance and a network connection. It never falls back to synthetic data if the fetch fails.

python main.py --ticker SYM

A different fit

Spline instead of RBF, strike instead of log-moneyness on the x axis, and no browser launch.

python main.py --method spline --x-axis strike --no-open

What it does not claim

  • The calendar and butterfly checks are diagnostics. They count violations at nodes inside the quoted range; they do not make the surface arbitrage-free, and the vertical-spread bound is not checked.
  • The 3D surface in the generated dashboard does not label extrapolated corners. The smile and term-structure panels do show the gaps.
  • A live ticker run prices American-style listed options with European Black-Scholes and a flat rate and dividend yield, and says so on the console.
  • Rates are a single number you pass in, not a market curve.
